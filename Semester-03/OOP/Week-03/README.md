# OOP Lab 3 - Circle Class

## Objective
To implement a Circle class in C++ using constructors, mutator and accessor functions.

## Concepts Covered
- Classes and Objects
- Private Data Members
- Default Constructor
- Parameterized Constructor
- Mutator Function: `setRadius()`
- Accessor Function: `getRadius()`
- Area Calculation
- Diameter Calculation
- Circumference Calculation
- Array of Objects

## Formulas
- Area = pi * radius * radius
- Diameter = 2 * radius
- Circumference = 2 * pi * radius

## Programming Language
C++
